## Описание плагина
**Smart Wrapper** — расширение, которое оборачивает выделенный фрагмент кода в базовые управляющие конструкции: `if`, `else if`, `else`, `while`, `for`, `do-while`. Плагин автоматически следит за отступами, что ускоряет написание кода.

## Возможности
- Обёртка выделенного кода в `if (условие) { ... }`
- Обёртка в `else if (условие) { ... }` и `else { ... }`
- Обёртка в `while (условие) { ... }`
- Обёртка в `for (заголовок) { ... }`
- Обёртка в `do { ... } while (условие);`
- Автоматическое сохранение и увеличение отступов

### Пример использования
**Было:**
```
x /= 2;
count++;
```
**Стало** (После Ctrl+ALt+W -> while -> count <= x) :
```
while (count <= x){
    x /= 2;
    count++;
}
```

## Использование
1. Выделите фрагмент кода.
2. Нажмите **`Ctrl+Alt+W`** (или `Cmd+Alt+W` на macOS).
3. В появившемся списке выберите нужную конструкцию.
4. При необходимости введите условие или заголовок цикла.
