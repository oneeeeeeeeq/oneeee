# Описание функций и архитектура плагина

## Команды и функции

### Команда: `smartWrapper.wrap`

**Описание:** Главная команда. Запрашивает у пользователя тип конструкции (if, for и т.д.) и оборачивает в неё выделенный код.

**Параметры:**
* `Выделенный код`: Текст, к которому применяется обёртка.
* `Условие / Заголовок`: Вводится пользователем в диалоговом окне (например: `x > 0`).

**Возвращаемое значение:**
* Действие: Изменяет текст документа, добавляя скобки и отступы.

---

### Функция: `make(c)`

**Описание:** Генерирует строки для вставки до и после выделенного кода.

**Параметры:**
* `c` (string): Введенное пользователем условие.

**Возвращаемое значение:**
* `Array[2]`: Массив из двух строк — открывающая и закрывающая конструкция. 
  * Пример: `['if (x > 0) {', '}']`

---

### Функция: `activate(context)`

**Описание:** Точка входа плагина. Регистрирует команду в VS Code при первом запуске.

**Параметры:**
* `context` (ExtensionContext): Служебный объект VS Code для управления ресурсами плагина.

**Возвращаемое значение:**
* `void` (ничего не возвращает).

## Архитектура плагина

Плагин **Smart Wrapper** состоит из двух ключевых файлов:

1. **`package.json` (Манифест)** — описывает плагин для VS Code. В нём объявлена команда (`smartWrapper.wrap`), указана горячая клавиша (`Ctrl+Alt+W`) и событие, по которому плагин активируется.

2. **`extension.js` (Исходный код)** — содержит логику работы. Функция `activate()` вызывается при первом нажатии горячей клавиши и регистрирует обработчик команды в системе.
